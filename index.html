    ChenRay 服务器规则¶

    欢迎来到 ChenRay 服务器（Minecraft / Paper）官方规则文档站。本站系统收录了服务器的全部官方规则、服务器信息、入服指引与常见问题解答，供玩家与管理员随时查阅。请在左侧导航选择对应文档，或使用顶部搜索框快速检索条款。

    服务器 QQ 群：108441415 ｜ 官网：www.chenray.top ｜ 主服地址：play.chenray.top:20577

    服务器简介¶

    ChenRay 服务器是一个由玩家共同建设、长期运营的 Minecraft 生存服务器，以 生存 · 红石 · 建筑 · 地铁 · 赛事 五大特色为核心，服务端采用 Paper（Minecraft Java 版），并同时向 Java 版与基岩版（Geyser）玩家开放。服务器坚持"规则面前人人平等"的理念，所有规则均经"七日阳光流程"公开修订，确保每一位玩家的知情权与参与权。

    特色玩法¶

    • 生存： 以原版生存为基础，玩家可在主世界自由发展，通过官方商店、任务、活动与赛事获取资源，享受原汁原味的生存体验
    • 红石： 服务器鼓励红石技术与自动化设计，玩家可在领地内自由搭建红石装置；大型红石机器须遵守公共区域与性能保护规范
    • 建筑： 采用"箭矢圈地 + 领地插件"双轨制管理领地，玩家可圈定私有领地安心建造；主城与公共区域受重点保护
    • 地铁： 服务器搭载 Metro 地铁插件，玩家可搭乘地铁在各大区域间快捷通行，地铁系统拥有独立的乘车管理条例
    • 赛事： 运营团队不定期举办建筑赛、红石赛、生存挑战等官方活动，优胜者可获得游戏币、称号等奖励

    服务器定位¶

    ChenRay 服务器面向所有喜爱 Minecraft 的玩家开放。无论是初入游戏的新人，还是深耕多年的老玩家，都能在这里找到属于自己的乐趣。服务器长期致力于营造公平、安全、友善、可持续的游戏环境，为此建立了完整的规则体系、处罚机制与申诉渠道。我们相信，规则的透明与公正，是服务器长治久安的基石。

    注意事项¶

    • 绑定改名： 群昵称会在绑定后自动变更为你的游戏 ID；如未自动更换，可手动更换
    • 数据互通： Java 与基岩版同 ID 账号下数据互通（主服适用；测试服是否互通请留意后续公告）

    玩家守则¶

    玩家守则是规范玩家在服务器内一切行为的基础性规章，适用于所有拥有或曾拥有本服白名单、账号及任何子服登录权限的玩家。守则共分十三章，涵盖以下内容：

    • 总则： 目的与原则（"先教育、后惩戒""处罚与教育相结合""程序正义"三大原则）、适用范围、术语定义
    • 游戏行为细则： 公平竞技（反外挂、漏洞报告与奖励、审查与举证）、建筑与领地、社交与聊天、经济系统、账号安全与共享
    • 处罚与申诉： 处罚梯度、累犯加重、申诉流程、赔偿机制
    • 特殊场景补充： 活动与竞赛、测试服、跨服联动、基岩版（Geyser）玩家
    • 专项细则： 入服与白名单、领地与建筑细则、经济与市场细则、聊天与社区细则、活动与赛事细则、纠纷仲裁、直播与录屏、账号数据保护
    • 附则： 修订与生效（七日阳光流程）、冲突条款、最终解释权、官方渠道与联系方式

    玩家守则确立了"默示接受原则"——玩家一经进入服务器或官方社群，即视为已完整阅读、充分理解并无条件接受守则全部条款，任何违规行为均不能以"不知情""没看到"作为抗辩理由。

    管理员条例¶

    管理员条例是规范管理员行为的专门条例，同时也是违规封禁规范的权威载体。条例共分五个部分：

    • 总体原则： 管理员的职责定位、权限边界与基本行为准则
    • 禁止行为： 明确列举管理员不得从事的各类行为，如滥用权限、徇私舞弊、泄露玩家隐私等
    • 职责要求： 值班、受理、调查、处罚、公示等日常管理职责的细化要求
    • 处罚逻辑： 处罚的分级、裁量、加重与减档逻辑
    • 违规封禁规范： 第八条 封禁分级与时长、第九条 违规封禁对照表（七大类 500+ 条：语言/破坏/作弊/经济/账号/管理/群聊社区）、第十条 封禁流程、第十一条 累计加重规则、第十二条 申诉与解封、第十三条 公示与记录、第十四条 反作弊与申诉

    违规封禁对照表是处罚执行的"法定标准"，对每一种违规情形都给出了首犯/再犯/累犯三档封禁标准，确保同类违规同等处罚，杜绝处罚的随意性。

    地铁乘车管理条例¶

    地铁乘车管理条例是地铁系统的专项规范，依据 Metro 插件功能制定。条例涵盖设施保护、乘车行为、特殊场景与管理职责四个部分：

    • 设施保护： 地铁站台、轨道、列车等设施的完整性与使用规范
    • 乘车行为： 购票、候车、乘车、下车的完整行为规范，以及逃票等违规行为的认定与处罚
    • 特殊场景： 高峰期、检修期、突发事件等特殊情形下的乘车要求
    • 管理职责： 地铁系统的日常管理、举报核实与处罚公示

    值得注意的是，Metro 插件的开发人员 angushushu 与 FZaoao 被认定为插件作者，仅豁免与乘车、设施使用相关的条款约束，其游戏内行为仍受玩家守则及管理员条例约束。

    规则修订：七日阳光流程¶

    "七日阳光流程" 是 ChenRay 服务器一切规则修订必须遵循的公开透明流程。它的核心只有一句话：规则不能"偷偷"改——任何修订草案都必须先在官方渠道公示满 7 日，充分收集玩家意见后方可生效。之所以取名"阳光"，是取"阳光下没有阴影"之意，代表整个修订过程全程公开、可查询、可追溯，不存在任何暗箱操作的空间。

    为什么需要这套流程¶

    规则是全体玩家共同遵守的行为契约，它的每一次变动都直接影响每个人的游戏体验。如果规则可以随意、悄悄修改，玩家将无法预判自己的行为是否合规，权益也无从保障。为此，ChenRay 运营团队确立了三条基本原则：

    1. 知情权：每一位玩家都有权利在规则生效之前，完整知晓"将要改什么、为什么改、什么时候生效"
    2. 参与权：玩家不是规则的被动接受者，而是规则的共同制定者；公示期内任何人都可以提出意见与建议
    3. 透明度：修订的全过程（草案、意见、表决、生效、登记）全部留痕，任何一条规则都能追溯到它从草稿到落地的完整旅程

    这三大原则共同构成了"七日阳光流程"的精神内核：规则因公开而可信，因参与而合理，因透明而长久。

    流程详解¶

    "七日阳光流程"共分四个环节，环环相扣：

    第一步：提交草案。 运营团队在酝酿任何规则变更时，必须先行形成书面修订草案，草案中要明确列出新增、删减或修改的每一条条款，并说明变更理由。草案一经形成，须同时在 QQ 群公告与游戏内公告栏两个官方渠道同步发布，并开放意见收集通道，任何玩家都可以在公示期内反馈看法。

    第二步：公示与意见收集。 草案发布后进入为期 7 日的公示期。公示期内，玩家可以在意见收集帖中提出支持、反对或修改建议；管理员团队也会同步梳理、汇总各方意见。公示期不是"走过场"，每一条有价值的意见都会被认真对待，必要时运营团队会就争议条款与玩家直接沟通。

    第三步：表决与生效。 公示期满后视意见情况分两种结果：

    • 七日内无重大反对意见的，草案自动转为正式版并即时生效，旧版本同时废止
    • 存在重大分歧的，公示期延长至 14 日，运营团队将针对分歧条款组织讨论，必要时召开线上听证会，听取各方陈述后再行表决

    无论哪种结果，生效决定都须再次向全体玩家公告说明。

    第四步：登记与追溯。 每次修订完成后，运营团队会在公告末尾附上本次修订的版本号与生效时间戳，并在仓库的 CHANGELOG.md 中登记变更条目。这意味着任何一条现行规则，都可以反查到"它在哪个版本被修改、改了什么、何时生效"，真正做到有据可查、有迹可循。

    特殊情形¶

    紧急修订。 涉及服务器安全、数据安全或严重漏洞的紧急修复，可以跳过公示期直接修订并立即生效——这是"阳光流程"唯一的例外。但紧急修订并非没有约束：须在 24 小时内补发公示，向全体玩家说明变更内容与原因，在 CHANGELOG.md 中登记，并接受运营团队的后续复核。也就是说，即便是紧急情况，"阳光"也会在一天之内重新照进来。

    专项条例同步。 除玩家守则外，管理员条例、地铁乘车管理条例等专项规则同样适用本流程。例如地铁乘车管理条例规定，修订版须公示 7 天后方可生效；因插件版本更新引发的调整除外，此类调整由插件作者与运营团队评估后执行。

    玩家可以做什么¶

    作为玩家，你可以：

    • 关注 QQ 群公告与游戏内公告栏，及时了解正在公示的修订草案
    • 在公示期内通过意见收集通道提交你的看法，无论赞成还是反对
    • 对任何"悄悄改规则"的行为提出质疑——因为按流程，这是不被允许的
    • 通过 CHANGELOG.md 查阅历次修订记录，掌握规则的完整演进历史

    入服指引¶

    第一步：加入官方 QQ 群¶

    加入官方 QQ 群 108441415，在群内了解服务器基本情况，获取最新公告与入服帮助。入群后请将群昵称设置为你的游戏 ID（若已在其他服务器使用其他昵称，请以游戏 ID 为准），便于他人识别与你自己的账号绑定。

    第二步：阅读规则¶

    完整阅读本规则站的《玩家守则》及《管理员条例》，确认无异议。规则是你在服务器内一切行为的依据，建议在首次进入服务器前认真阅读全文，了解自身权利与义务。

    第三步：尝试进服¶

    直接连接服务器地址尝试进入游戏：

    • Java 版： play.chenray.top:20577
    • 基岩版： play.chenray.top（端口 20577）

    进服时，服务器会显示一条 "绑定 xxxx" 的提示信息，其中 xxxx 为服务器为该玩家自动生成的随机绑定码。

    第四步：发送绑定码¶

    将显示的绑定码发送到官方 QQ 群。群内机器人自动识别绑定码并核对，核对无误后自动为玩家添加白名单，玩家即可正常登录游戏。绑定流程全自动，通常在发送绑定码后即时生效。

    第五步：开启你的服务器之旅¶

    绑定成功后，你就可以开始探索服务器了。建议新人：

    • 熟悉常用指令与插件用法（tpa、sethome、home、grave、back 等）
    • 了解主城及公共设施分布
    • 加入官方社群及时获取公告与活动信息
    • 遇到问题及时求助值班管理员

    新人享有一定时长的保护期，保护期内轻微违规以教育引导为主，酌情从轻处理。但请记住：保护期并非"免责期"，严重违规行为同样会受到处罚。

    常见问题（FAQ）¶

    如何获得白名单？¶

    进服获取绑定码 → 发送至官方 QQ 群（108441415）→ 机器人自动绑定。绑定失败时，可能原因包括绑定码输入错误、绑定码已失效、玩家存在违规或黑名单记录。多次尝试仍无法绑定的，请 @值班管理员 寻求人工协助。

    如何举报违规玩家？¶

    通过"举报通道"提交证据（截图、录像、日志等），管理员将在 12 小时内启动调查。处罚结果将公示在公告区，接受玩家监督。举报时请尽量提供完整、清晰的证据材料，证据是公正处罚的基础。

    被封禁了如何申诉？¶

    通过官网或 QQ 群按模板提交申诉，写明 ID、违规时间、管理员、申诉理由及新证据。非当事两名管理员将在 72 小时内联合审查并给出结论。申诉期间账号维持原处罚状态；申诉成功立即解除处罚并公开道歉。

    交易纠纷如何处理？¶

    交易纠纷先双方协商，协商不成走举报通道仲裁，12 小时内受理。仲裁需提供双方 ID、交易内容与证据。仲裁结果即为最终结论，原则上不再受理重复仲裁。

    如何购买或租用店铺？¶

    服务器商铺通过告示牌公开售卖，待出租或出售的店铺旁设有出租告示牌，标注租金价格与永久购买价格。按告示牌标价购买或租用即可，请勿私下议价。店铺相关手续请联系阿清办理（QQ：2717104909），经营须办理营业执照。

    发现服务器漏洞怎么办？¶

    通过工单提交详细复现步骤（漏洞触发条件、操作流程及影响范围）。经确认属于首例重大漏洞者，视影响范围给予 500–5000 游戏币或等值物品奖励，并视情况发放"漏洞猎人"纪念称号。请勿利用漏洞牟利——先利用漏洞后主动报告者不免责。

    账号被盗了怎么办？¶

    提供注册邮箱、历史登录 IP、最早建筑坐标等证据，经管理员核对后找回；证据不足的，可冻结账号直至争议解决。请务必保管好账号密码，不要共享、代练、买卖账号（双方同封）。

    基岩版玩家有什么需要注意的？¶

    基岩版玩家与 Java 版玩家享有同等权利、承担同等义务，主服数据互通。反作弊对基岩版玩家豁免自动检测，但外挂仍属禁止（Toolbox 等基岩端外挂照封）。基岩版客户端无法加载 Java Mod 与资源包，但不得以此为由违反规则或逃避处罚。

    如何参与活动与赛事？¶

    关注 QQ 群公告与游戏内公告栏，官方活动规则会另行公告。活动规则与守则冲突时以活动规则为准，活动结束后自动恢复守则适用。优胜者可获得游戏币、称号等奖励。

    测试服和正式服有什么区别？¶

    测试服是运营团队用于版本测试、插件验证的专用服务器。测试服数据不与正式服互通，可删除或回档，不另作补偿。测试服中的违规行为同样记录在案，情节严重者将同步封禁正式服账号。

    直播或录屏需要注意什么？¶

    服务器允许玩家在遵守规则的前提下进行直播与录屏，但不得传播违规内容、泄露他人隐私或未经授权进行商业用途。具体规范见玩家守则第十一章。
