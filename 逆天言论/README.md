# 逆天言论HUB

> [!NOTE]
> 此仓库纯属娱乐，请勿上升到人身攻击。建议多贡献点图片。

## 这是什么

这是一个由阿清创建的收集群里言论 / 表情包的存放仓库，以方便查看黑历史。

## 📦 自动打包

每当有新的图片推送，GitHub Actions 会自动把所有图片打包成 zip 并发布到 [Releases](https://github.com/ChenRay-team/ChenRay-Docs/releases/tag/latest)，群友可随时下载最新合集。

## 如何提交逆天发言

1. 表情包和群友集体发言直接放在本目录（`逆天言论HUB/`）下即可
2. 根据你要提交者的名字放入相应的文件夹中，如果没有可以创建
3. 图片的命名请不要使用杂乱的名称
4. 图片文件命名建议使用简短的文字概括
5. 不要提交不相关的图片内容
6. 如果 PR 数大于 5，可以开 issue 要贡献者权限

## 可以用来做什么

1. 可以随便发在群里面，帮助群友回忆黑历史

本仓库采用[逆天言论HUB 许可证](LICENSE)：

- 允许：群里随便发、互相调侃、转发传播、贡献图片
