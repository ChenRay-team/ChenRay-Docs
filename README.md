## 规则修订：七日阳光流程

**"七日阳光流程"** 是 ChenRay 服务器一切规则修订必须遵循的公开透明流程。它的核心只有一句话：**规则不能"偷偷"改——任何修订草案都必须先在官方渠道公示满 7 日，充分收集玩家意见后方可生效**。之所以取名"阳光"，是取"阳光下没有阴影"之意，代表整个修订过程全程公开、可查询、可追溯，不存在任何暗箱操作的空间。

### 为什么需要这套流程

规则是全体玩家共同遵守的行为契约，它的每一次变动都直接影响每个人的游戏体验。如果规则可以随意、悄悄修改，玩家将无法预判自己的行为是否合规，权益也无从保障。为此，ChenRay 运营团队确立了三条基本原则：

1. **知情权**：每一位玩家都有权利在规则生效之前，完整知晓"将要改什么、为什么改、什么时候生效"
2. **参与权**：玩家不是规则的被动接受者，而是规则的共同制定者；公示期内任何人都可以提出意见与建议
3. **透明度**：修订的全过程（草案、意见、表决、生效、登记）全部留痕，任何一条规则都能追溯到它从草稿到落地的完整旅程

这三大原则共同构成了"七日阳光流程"的精神内核：**规则因公开而可信，因参与而合理，因透明而长久**。

### 流程详解

"七日阳光流程"共分四个环节，环环相扣：

**第一步：提交草案。** 运营团队在酝酿任何规则变更时，必须先行形成书面修订草案，草案中要**明确列出新增、删减或修改的每一条条款**，并说明变更理由。草案一经形成，须同时在 **QQ 群公告**与**游戏内公告栏**两个官方渠道同步发布，并开放意见收集通道，任何玩家都可以在公示期内反馈看法。

**第二步：公示与意见收集。** 草案发布后进入为期 **7 日**的公示期。公示期内，玩家可以在意见收集帖中提出支持、反对或修改建议；管理员团队也会同步梳理、汇总各方意见。公示期不是"走过场"，每一条有价值的意见都会被认真对待，必要时运营团队会就争议条款与玩家直接沟通。

**第三步：表决与生效。** 公示期满后视意见情况分两种结果：

- 七日内**无重大反对意见**的，草案自动转为正式版并即时生效，旧版本同时废止
- 存在**重大分歧**的，公示期延长至 **14 日**，运营团队将针对分歧条款组织讨论，必要时召开**线上听证会**，听取各方陈述后再行表决

无论哪种结果，生效决定都须再次向全体玩家公告说明。

**第四步：登记与追溯。** 每次修订完成后，运营团队会在公告末尾附上本次修订的**版本号与生效时间戳**，并在仓库的 `CHANGELOG.md` 中登记变更条目。这意味着任何一条现行规则，都可以反查到"它在哪个版本被修改、改了什么、何时生效"，真正做到有据可查、有迹可循。

### 特殊情形

**紧急修订。** 涉及服务器安全、数据安全或严重漏洞的紧急修复，可以跳过公示期直接修订并立即生效——这是"阳光流程"唯一的例外。但紧急修订并非没有约束：须在 **24 小时内**补发公示，向全体玩家说明变更内容与原因，在 `CHANGELOG.md` 中登记，并接受运营团队的后续复核。也就是说，即便是紧急情况，"阳光"也会在一天之内重新照进来。

**专项条例同步。** 除玩家守则外，管理员条例、地铁乘车管理条例等专项规则同样适用本流程。例如地铁乘车管理条例规定，修订版须公示 **7 天**后方可生效；因插件版本更新引发的调整除外，此类调整由插件作者与运营团队评估后执行。

### 玩家可以做什么

作为玩家，你可以：

- 关注 QQ 群公告与游戏内公告栏，及时了解正在公示的修订草案
- 在公示期内通过意见收集通道提交你的看法，无论赞成还是反对
- 对任何"悄悄改规则"的行为提出质疑——因为按流程，这是不被允许的
- 通过 `CHANGELOG.md` 查阅历次修订记录，掌握规则的完整演进历史

### 常见疑问

**Q1：公示期这么长，紧急情况怎么办？** 紧急修订通道正是为此设立的——安全类问题可先修后公示，但 24 小时内必须补全公示与登记，绝不留下无人知晓的"幽灵条款"。

**Q2：玩家提出的意见真的有用吗？** 有用。公示期收集的意见会逐条汇总评估，重大分歧会直接触发延长公示与线上听证会，这本身就是意见分量的最好证明。

**Q3：怎么知道某条规则是什么时候改的？** 每条现行规则都能在 `CHANGELOG.md` 和公告末尾的版本号与时间戳中反查到修改记录，全程可追溯。

### 一句话总结

**七日阳光流程 = 草案公开 + 公示七日 + 无反对即生效 + 全程留痕。** 它是 ChenRay 服务器"规则面前人人平等"的基石，也是运营团队对全体玩家最郑重的承诺：**每一次规则变动，都经得起阳光的审视。**
