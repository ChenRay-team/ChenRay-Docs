    ChenRay 玩家守则 · 省流版¶

    面向玩家的一页速查，只写重点。详细条款见 玩家守则。

    入服¶

    • 进服看提示的 "绑定 xxxx"，把绑定码发到 QQ 群 108441415，机器人自动加白名单
    • 群昵称建议与游戏 ID 一致，便于识别

    红线（碰了会被封）¶

    • ❌ 外挂、脚本、透视、自动点击、杀戮光环
    • ❌ 卡漏洞刷物品、刷钱、刷经验
    • ❌ 偷东西、拆别人家、恶意破坏
    • ❌ 辱骂、歧视、人身攻击、人肉搜索
    • ❌ 刷屏、广告、钓鱼 / 病毒链接
    • ❌ RMT（用现实钱买游戏物品 / 货币）
    • ❌ 账号共享、代练、买卖账号
    • 累犯加重：30 天内第二次 处罚上调，第三次 顶格处理

    领地与建筑¶

    • 圈地后 7 天内 竖告示牌写明用途 + 主人 ID，否则可被强制拆除
    • 主城及周边 100 格 内禁止建筑、挖掘、种植、PVP、倒水 / 岩浆
    • 公共设施改动需工单申请，两名管理员同意 才可动
    • 禁止超大地形改造（>100×100）、Y=5 以下整层挖、128×128 竖井

    经济与商店¶

    • 货币靠官方渠道赚：商店、任务、活动、赛事、拍卖行
    • 开店必须明码标价，禁止"面议""私聊报价"
    • 店铺：看店旁出租告示牌标价购买或租用，手续找阿清（QQ 2717104909）
    • 开店必须办营业执照（阿清办理）；别欠租、别乱转租、别涂改告示牌

    账号安全¶

    • 保管好账号密码，别共享、别代练、别买卖（双方同封）
    • 账号被盗：提供注册邮箱、历史登录 IP、最早建筑坐标等证据找回

    聊天¶

    • 公共频道用简体中文
    • 被私聊骚扰：截图 → 群内 @值班管理员 举报
    • 禁止冒充管理员、假冒系统消息、伪造公告

    活动与纠纷¶

    • 活动规则以公告为准，与守则冲突时以活动规则为准
    • 纠纷先协商，协商不成走举报通道仲裁，12 小时内 受理

    基岩版（手机 / 平板 / Geyser）¶

    • 基岩版与 Java 版规则相同，主服数据互通
    • 绑定流程一样：绑定码发 QQ 群
    • 反作弊对基岩版豁免自动检测，但外挂仍禁止（人工核查 / 举报照样处罚）
    • 外挂同样禁止（Toolbox 等基岩端外挂照封）

    假人（FakePlayer）¶

    • 假人 = 自动化"替身"，可帮你挖矿、打怪、点击交互；头顶标有 "bot by 你"，不算真人
    • 免费 1 个，想多要可租赁（按小时付费，到期自动清理）
    • ❌ 禁止用假人刷资源、刷钱、卡漏洞、冒充真人骗人
    • ❌ 禁止在别人家 / 公共区域乱堆假人、堵路、恶意干扰他人
    • 别人的假人归别人管，不许乱动；在他人领地用假人要先征得同意
    • 详细玩法见 假人使用教程

    处罚与申诉¶

    • 处罚分级：警告 → 短期（1 小时–7 天）→ 中期（7–30 天）→ 长期（30–180 天）→ 永久
    • 被误封：官网 / QQ 群提交申诉，72 小时内 两名非当事管理员复查
    • 举证期 7 天，逾期视为放弃
    • 因误封造成损失，按商店价 1.5 倍 赔偿

    常用入口¶

    • 官方 QQ 群： 108441415
    • 举报通道 / 申诉区： 游戏内、群内 @值班管理员、官网
    • 官网： www.chenray.top
