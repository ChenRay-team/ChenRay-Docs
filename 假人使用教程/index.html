    🤖 假人（FakePlayer）使用教程¶

    假人是 ChenRay 服务器提供的"替身"功能：它会在你身边生成一个模拟玩家，可以像真人一样站立、移动，按照你的指令自动挖掘方块、点击交互、攻击怪物，甚至在你离开忙别的事情时，帮你持续挂机干活。

    本教程面向普通玩家，详细介绍假人的每一项功能与使用技巧。管理员专属的指令（一键清除、转移归属、健康检查等）不在本教程范围内。

    一、假人是什么？¶

    假人（FakePlayer），是服务器专门为玩家准备的自动化帮手。你可以把它理解成一个"人形工具人"：它长得和普通玩家几乎一样，有自己的名字、皮肤和头顶名牌，但它完全听命于生成它的玩家。

    1.1 假人的标识¶

    每个假人的头顶都会显示一行标识，写着 "bot by 你的名字"。这行标识是插件强制添加的，无法去掉。它的作用有两个：一是让所有人一眼就能认出这是个机器人，而不是挂机的真人；二是防止有人利用假人冒充普通玩家进行欺骗。所以哪怕你把假人改成了再普通的名字，别人也能通过这行标识认出它是机器人。

    1.2 假人的归属¶

    假人有严格的归属机制：谁生成的假人就归谁指挥。其他玩家既不能操作你的假人，也不能把它占为己有，更不能删除或改名你的假人。只有生成它的玩家和服务器管理员有权管理它。这套机制保证了假人不会成为"抢怪""偷东西"的工具。

    1.3 假人的特点¶

    • 假人不会在聊天频道里说话，也不会广播加入、离开、死亡之类的消息，非常安静。
    • 假人可以被传送、可以被收取经验、可以被删除，也可以按小时付费租用。
    • 假人的皮肤默认取自服务器的皮肤池，也可能随机使用稀有皮肤，看起来和普通玩家几乎一样。
    • 假人头顶的悬浮文字会实时显示它当前的状态，比如空闲、挖掘、战斗、移动等，非常直观。

    1.4 假人能做什么¶

    假人能帮你做的事情非常多：让它在自动农场里持续收获作物、在刷怪塔里帮你清理怪物并收集经验、在流水线的一环上反复点击某个开关、在建筑时让它站在特定位置帮你"打下手"。总而言之，凡是需要反复点击、反复挖掘的机械性工作，假人都能胜任。

    重要提醒：假人虽然好用，但也请遵守服务器规则。不要用假人干扰其他玩家的正常游戏，不要在公共区域大量堆放假人造成卡顿，更不要利用假人进行任何违规行为。合理使用假人，它会是你的得力助手；滥用假人，则可能给服务器和大家带来困扰。

    1.5 常见误解¶

    很多新手玩家对假人存在一些误解，这里一并澄清：

    • 误解一：假人会自己主动干活。 实际上，假人只会执行你明确下达的指令。生成之后它默认是站着的，需要你用左键、右键、移动等指令告诉它要做什么，它才会动起来。
    • 误解二：假人算真人玩家。 不算。假人不会进入服务器的在线人数统计，也不参与任何面向真人的机制（比如排行榜、在线奖励等）。它只是一个自动化工具。
    • 误解三：假人会被其他玩家攻击或偷走。 假人有自己的归属与保护机制，其他玩家既不能攻击伤害它，也不能把它占为己有。具体保护程度以服务器配置为准。
    • 误解四：删除假人等于删档。 删除假人只是移除这个模拟玩家，不会影响你的任何游戏数据。假人身上的物品和经验按服务器设置处理，你自己的背包、仓库、家园等完全不受影响。

    理解了这些，你就能更安心地使用假人了。

    二、使用前提与权限¶

    2.1 需要什么条件¶

    使用假人功能的前提是：你拥有对应的权限。服务器管理员可以为玩家分配不同层级的假人权限，包括生成、操控、删除、租赁等。如果你执行某条指令时收到"没有权限"的提示，说明管理员尚未为你开放该权限，请联系管理员开通。

    2.2 权限与角色¶

    • 普通玩家：默认拥有生成、操控、查看、删除自己假人等基础权限，通常默认可以拥有 1 个免费假人。
    • 进阶玩家：管理员可以为表现良好的玩家提升假人数量上限，或开放更多高级功能。
    • 管理员：拥有假人系统的全部管理权限，包括一键清除、转移归属、修改配置等。

    2.3 权限不足怎么办¶

    遇到"没有权限"的提示时，先确认是不是指令用法写错了。如果指令本身没问题，那就是权限未开通。此时可以：

    1. 在游戏里输入 /fpp help，查看当前权限范围内能使用的指令。
    2. 直接联系管理员，说明你想使用的功能，管理员会根据需要为你开通权限。

    三、命令前缀与帮助¶

    3.1 命令前缀¶

    插件的所有指令都以 /fpp 开头，但同时也提供了几个完全等效的别名，你可以任意使用其中一个，效果完全一样：

    • /fpp
    • /bot
    • /fakeplayer
    • /fp

    举个例子，/fpp spawn 和 /bot spawn 是同一个指令，只是写法不同。本教程的示例统一使用 /fpp 前缀，你把示例中的 /fpp 换成 /bot 也完全没问题。

    3.2 帮助菜单¶

    如果你忘记了某个指令的具体用法，随时可以输入：

    text /fpp helptext

    这条指令会打开游戏内的帮助菜单，列出当前你权限范围内所有能使用的指令以及它们的简要说明。帮助菜单是分页显示的，可以翻页浏览。这是快速回忆指令用法的最好方式。菜单里只会显示你有权限使用的指令，权限不够的指令是不会出现的。

    四、快速上手速查表¶

    下表列出最常用的指令，方便你快速开始使用假人功能：

    你想做的事 输入指令
    生成一个假人 /fpp spawn
    生成指定名字的假人 /fpp spawn --name Miner
    把假人传回身边 /fpp tph bot
    传送到假人身边 /fpp tp bot
    查看假人信息 /fpp info bot
    查看服务器所有假人 /fpp list
    让假人走到指定坐标 /fpp move bot --coords 100 64 -200
    让假人跟着你走 /fpp move bot --to 你的名字
    让假人挖一下或打一下 /fpp left-click bot --once
    让假人右键一下 /fpp right-click bot --once
    让假人搜索附近方块 /fpp find bot 钻石矿石 --radius 20
    打开假人背包 /fpp inventory bot
    让假人蹲下 /fpp sneak bot on
    收走假人的经验 /fpp xp bot
    删除自己的假人 /fpp despawn --own
    租一个假人（付费） /fpp rent buy 4
    打开假人设置 /fpp settings bot

    第一次生成后，假人会按照顺序自动命名：bot、bot2、bot3……依次递增。当然，你也可以在生成时自己指定一个更有个性的名字。

    五、生成假人¶

    5.1 基础生成¶

    最简单的方式，直接输入：

    text /fpp spawntext

    指令会在你脚下生成一个假人，并自动给它起一个名字。生成之后，假人会站在你身边，等待你的下一步指令。

    需要特别注意的是：生成假人必须由玩家在游戏内亲自执行，控制台或后台是无法生成假人的。而且假人总是生成在你当前所在的位置，也就是以你自己为参照点，不能指定生成到某个遥远的世界坐标。

    5.2 自定义名字¶

    如果你希望假人有一个更有辨识度的名字，方便在多个人一起使用时区分，可以使用 --name 参数：

    text /fpp spawn --name Minertext

    关于名字，有一些限制需要提前了解：

    • 长度限制为 1 到 16 个字符。
    • 只能使用字母、数字和下划线，不支持中文。
    • 不能和当前在线玩家的名字重复。
    • 不能包含服务器设定的违禁词，否则会被拒绝或自动改名。

    即使你给假人起了自定义名字，假人头顶依然会保留"bot by 你"的标识，所以完全不用担心假人被其他人误认成真人。

    5.3 关于个人上限¶

    普通玩家默认最多同时拥有 1 个假人。当你的假人数量达到这个上限时，再次生成会提示"已达到上限"。

    如果你确实需要更多的假人，可以通过以下几种方式解决：

    1. 先删除现有的假人，再生成新的，让名额腾出来。
    2. 使用租赁功能，付费租用额外的假人（详见"租赁假人"一节）。
    3. 联系管理员，请他们为你提升个人假人上限。

    假人上限的设定主要是为了保护服务器性能，避免同一时间出现过多假人导致服务器卡顿，所以请合理使用名额。

    另外补充一点：当你使用 /fpp spawn 生成假人时，插件会自动检查名字是否合法、是否与在线玩家重名、是否包含违禁词等。如果名字不合格，指令会被拒绝，并提示具体原因，你换一个名字重新生成即可，不会产生任何损失。

    5.4 生成失败的常见原因¶

    生成假人失败时，通常可以在提示信息里找到原因。常见的情况有：

    • 名字不合法：名字里包含中文、空格或特殊符号，或者长度不在 1~16 字符范围内。换一个符合规则的字母数字名字即可。
    • 与在线玩家重名：假人不能和当前在线的真人玩家重名，换一个名字再试。
    • 包含违禁词：名字里包含服务器设定的违禁词，会被拒绝，或者自动改成安全的名字。
    • 达到数量上限：你的假人数量已经达到个人上限。删除旧假人、租赁新假人，或者联系管理员提升上限后即可再次生成。

    生成失败不会造成任何损失，也不会扣费，你可以放心反复尝试。

    六、管理假人¶

    6.1 查看假人列表¶

    text /fpp listtext

    这条指令会列出当前服务器上所有活跃的假人，方便你确认自己手上有哪些假人、它们的名字是什么。尤其是假人一多的时候，先用 /fpp list 看清再操作，就不容易搞混。

    6.2 查看假人信息¶

    text /fpp info bottext

    信息中会显示假人当前所在的位置、已经存在的时间等内容，帮助你判断它是否还在正常工作、是否还在原来的地方。如果你不小心把假人弄丢了，先用这条指令确认它是否还在，再用传送指令把它找回来。

    6.3 改名¶

    text /fpp rename bot 新名字text

    修改假人的显示名字，头顶名牌、列表里的名字都会同步更新。改名的规则和生成时的命名规则一样（1~16 个字符，字母、数字、下划线），而且头顶的"bot by 你"标识会一直保留，不用担心被认成真人。如果你觉得假人自动起的名字不好记，给它起一个顺口的名字会方便很多。

    6.4 删除假人¶

    当你不再需要某个假人时，可以把它删除：

    text /fpp despawn --owntext

    这里的 --own 参数表示只删除你自己生成的那些假人，不会影响到其他玩家的假人，使用起来非常安全。有几点需要特别说明：

    • 如果执行这条指令时提示"你没有权限"，说明管理员还没有开放玩家删除假人的功能。你可以联系管理员，请他们为你开通权限。
    • 删除别人的假人、一键清除所有假人，这些都属于管理员功能。普通玩家无法使用这些指令，也绝对无法删除其他玩家生成的假人。
    • 删除假人之前，建议先确认它身上有没有贵重物品或大量经验。删除后假人身上的物品和经验会按照服务器的设置处理，有些设置会保留下来，有些则不会。

    七、操控假人¶

    7.1 传送假人¶

    如果你走远了，想让假人跟着你转移到新的地点，可以使用传送指令：

    text /fpp tph bottext

    这条指令会把指定的假人直接传送到你的身边，省去你跑回去找它的麻烦。无论是换地方挖矿，还是换个区域干活，这条指令都能让假人迅速跟上你。

    如果你想主动传送到假人身边，可以用：

    text /fpp tp bottext

    7.2 让假人移动¶

    假人不光能站在原地干活，还能按你的要求自己走过去。假人会自动寻路，绕开障碍走到目标地点：

    text /fpp move bot --to 你的名字 让假人走到你身边，并且会持续跟着你移动 /fpp move bot --to bot2 让假人走到另一个假人身边 /fpp move bot --coords 100 64 -200 让假人走到指定坐标 /fpp move bot --stop 停止移动text

    其中 --to 后面既可以跟真人玩家，也可以跟另一个假人。跟真人时假人会一路跟着他，非常适合当"小跟班"一起行动；跟坐标时假人会走到那个精确位置，适合搬运、站位等场景。

    7.3 自动挖掘或攻击（左键）¶

    这是假人最常用的功能。假人可以代替你，对着某个目标执行左键操作，也就是挖掘方块或者攻击生物：

    text /fpp left-click bot --oncetext

    使用这条指令时有几个关键要点：

    • 指令中的 --once 表示只执行一次，假人做完就停，不会一直重复。
    • 假人执行的目标，是你输入指令那一刻眼睛所瞄准的点。所以请先面向目标，再输入指令。
    • 如果目标距离假人比较远，假人会自己寻路，走到够得着目标的位置，再开始行动。

    举个例子：你想让假人帮你挖掉一块铁矿石。你只需要站好，让视线对准那块铁矿石，然后输入 /fpp left-click bot --once，假人就会走过去，把那块铁矿石挖掉。

    这里还有一个细节：假人执行左键时，会对准你瞄准的精确位置动手，而不是草草地对着方块表面。如果目标在够不到的位置，假人会先自己寻找一个合适的落脚点，走到能碰到目标的地方再开始。所以哪怕目标在墙壁后面、头顶上方，假人也会尽量想办法完成。

    如果你希望假人能够持续重复挖掘，比如让它连续挖一整片矿脉，可以使用重复模式：

    text /fpp left-click bot --repeattext

    重复模式下，假人会按照设定的间隔不断执行左键操作，适合自动挖矿、自动刷怪等场景。挖矿的时候也要注意，假人挖下来的方块会掉在原地，记得及时捡起来，别让物品消失。

    7.4 自动交互（右键）¶

    右键功能让假人可以代替你执行交互操作：

    text /fpp right-click bot --oncetext

    和左键类似，假人会对着你瞄准的方块或实体执行一次右键。常见的用途包括：

    • 打开箱子、木桶、潜影盒等容器。
    • 按下按钮、拉下拉杆，触发红石机关。
    • 使用手中的物品，比如锄头耕地、打火石点火、骨粉催熟作物等。

    使用方式与左键完全一样：先面向目标，再输入指令，假人会自己走到合适的位置执行操作。

    有一个小技巧值得记住：如果你想让假人右键某个开关，比如按钮或拉杆，一定要让假人的视线真正对准开关本身，而不是它附着的那个方块。多试几次角度，找准了假人就能顺利触发。

    右键功能的想象力空间很大：让假人帮你把耕地重新锄一遍、让假人对着农田持续使用骨粉催熟、让假人在箱子旁边帮你把物品放进去……只要是需要反复右键的操作，都可以尝试交给假人。持续右键使用 --repeat 模式即可。遇到拿不准的用法，先小范围测试几次，熟练之后再大规模使用。

    7.5 攻击与战斗¶

    text /fpp attack bot --oncetext

    让假人挥砍一次。更丰富的自动战斗设置（比如锁定目标、追击范围、攻击优先级等）可以在假人的设置界面里配置。如果你需要假人长时间清理怪物，可以配合刷怪塔使用，让假人站在刷怪塔下自动清理落下来的怪物。

    7.6 潜行与冻结¶

    text /fpp sneak bot on 让假人蹲下 /fpp sneak bot off 让假人站起来 /fpp sneak bot toggle 切换蹲下/站立状态 /fpp freeze bot on 冻结假人，让它原地站住不动 /fpp freeze bot off 解除冻结text

    蹲下状态有时在建筑或高处作业时很有用，比如让假人蹲在高台边缘干活，不容易滑落；冻结则适合在需要假人"乖乖站着"的场合使用，比如让它站在某个特定位置当"人形柱子"，或者防止它在干活时乱跑。

    7.7 停止任务¶

    text /fpp stop bot 停止某个假人的所有任务 /fpp stop all 停止你所有假人的任务text

    当假人正在做的任务已经完成、或者发现它在做无用功时，用这条指令让它停下来，省电也省心。停止任务只是让假人停下来，并不会删除假人，你随时可以给它安排新任务。

    7.8 让假人搜索方块¶

    text /fpp find bot 钻石矿石 --radius 20 /fpp find bot 绿宝石矿石 --radius 30 --count 5text

    让假人在指定半径范围内搜索某种方块，并报告找到的位置。想找矿、找特定建筑方块、或者确认某个区域里有没有某种资源时，都可以让假人先帮你探一探。--radius 控制搜索半径，--count 控制最多报告多少个位置。

    八、背包与存储¶

    8.1 查看假人背包¶

    text /fpp inventory bottext

    （也可以简写为 /fpp inv bot）

    这条指令会直接打开假人的背包，你可以查看它身上带了什么、有没有贵重物品，也可以往里面放进物品。在假人干活之前先检查一下它的装备和随身物品，能避免不少麻烦。

    8.2 假人的存储箱¶

    假人可以把挖到的东西存进附近的箱子里，避免物品掉一地：

    text /fpp storage bot --list 查看假人已登记的存储箱 /fpp storage bot --enable 箱子名 让假人记住这个箱子（先点一下要登记的箱子） /fpp storage bot --deposit 把假人背包里的物品存入存储箱text

    配合自动挖掘或自动收菜使用效果最好：假人挖到的东西可以直接存进箱子，你只需要定时去把箱子里的收获清走就行。这套"自动干活 + 自动入库"的组合，是假人挂机玩法的核心。

    8.3 物品管理建议¶

    • 开工前用 /fpp inventory bot 检查假人装备和工具，给假人配好镐子、锄头等工具。
    • 大量自动挖掘前，先给假人登记好附近的存储箱。
    • 记得定期用 /fpp storage bot --deposit 清空假人背包，防止背包满了之后物品掉落。

    九、经验管理¶

    假人在打怪、挖矿的过程中会积累经验值。这些经验值你可以随时收走：

    text /fpp xp bottext

    这样假人辛辛苦苦攒下的经验就不会白白浪费，你可以用来附魔装备、修复工具，或者做其他需要经验的事情。

    如果你经常让假人在刷怪塔挂机，建议养成定时收经验的好习惯：每隔一段时间回来用 /fpp xp bot 收走经验，积少成多，附魔装备就再也不缺经验了。

    十、租赁假人（按小时付费）¶

    服务器开放了假人租赁功能。你可以使用游戏货币，按小时租用假人，时间一到假人会自动清理，特别适合需要长时间挂机的玩家，也省去了自己记着手动删除的麻烦。

    10.1 常用指令¶

    text /fpp rent buy 4 花 400 货币，直接租一个 4 小时的假人 /fpp rent extend bot 3 给已有的假人续费 3 小时 /fpp rent info 查看自己所有假人的剩余时间 /fpp rent clear bot 提前清掉某个租用的假人text

    这几条指令非常好记：buy 是购买新的，extend 是给已有的续时间，info 是查看剩余时间，clear 是提前结束。只要记住这四个动作，租赁功能就基本掌握了。

    10.2 租赁规则¶

    • 单价：每小时 100 货币，具体价格以服务器公告为准。
    • 范围：单次可以租 1 到 72 小时。
    • 数量：同一时间最多可以租 3 个假人。
    • 提醒：剩余时间不足 10 分钟时，系统会发送消息提醒你，方便你及时续费。
    • 到期：时间用完后假人会自动清理，不需要你手动删除。

    10.3 什么情况适合租赁¶

    • 你需要离开一段时间，希望假人继续帮你挂机干活。
    • 你免费的 1 个假人名额已经用满，还想拥有更多假人同时工作。
    • 你不想记着删除假人，希望到点自动清理，省心省力。
    • 你只是临时需要假人帮一两个小时忙，用完自动消失，不用惦记。

    租赁和免费生成还有个重要区别：免费生成的假人会一直存在，直到你或管理员删除；而租赁的假人时间一到就自动清理，相当于帮你省去了手动管理的步骤。如果你经常需要临时借用假人，租赁会比反复生成再删除方便得多，还能避免忘记删除导致名额被长期占用。

    10.4 租赁的注意事项¶

    • 租赁之前系统会先检查你的余额，余额不足时指令会被拒绝，也不会生成假人，更不会扣你的钱，可以放心尝试。
    • 续费时要注意单个假人累计的剩余时间上限，避免无限囤积时长。
    • 如果你提前完成了任务，可以用 /fpp rent clear bot 提前清掉假人，减少不必要的花费。
    • 租赁的假人和免费生成的假人是分开计算名额的，你可以同时拥有免费的 1 个假人和租赁的假人，互不影响。

    十一、设置界面与个性化¶

    11.1 打开设置界面¶

    text /fpp settings bottext

    打开假人的交互式设置界面，可以调整假人的名字、行为方式、战斗配置、点击间隔等各项参数。界面里按分类展示，翻一翻就能找到想改的选项。

    11.2 可以调整什么¶

    • 名字：修改假人的显示名称。
    • 行为方式：调整假人在不同情况下的反应和动作。
    • 战斗配置：设置自动战斗的锁定目标、追击范围、攻击优先级等。
    • 点击间隔：调整假人重复点击的节奏，适合自己的需求。

    提示：以上进阶功能（移动、搜索、存储、改名、设置等）默认对玩家开放，但如果服务器做了权限调整，个别指令可能需要管理员为你开通对应权限。遇到"没有权限"的提示，直接联系管理员即可。

    十二、常见问题（FAQ）¶

    问：假人生成后不动，是怎么回事？ 答：挖掘和交互类指令都是以你瞄准的点为目标的。请先面向目标再输入指令，假人才会过去执行。另外，假人需要走到够得着目标的位置才会开始行动，距离太远时它会先寻路。

    问：假人突然不见了，是什么原因？ 答：常见原因有三个：一是租赁时间到期，系统自动清理了；二是被你自己删除掉了；三是被管理员处理了。如果服务器开启了持久化功能，重启之后假人会自动恢复。

    问：提示"已达到上限"怎么办？ 答：普通玩家默认只有 1 个假人名额。可以先删除旧假人腾出名额，或者改用租赁功能，也可以联系管理员提高你的个人上限。

    问：假人会攻击我，或者偷我的东西吗？ 答：不会。假人只听从生成它的玩家指挥，有严格的归属保护。其他玩家无法操作你的假人，假人也不会主动攻击真人玩家，更不会拿走你的东西。

    问：假人的名字能改成中文吗？ 答：不能。名字只支持字母、数字和下划线，这是服务器统一的规定，主要是为了保证兼容性和避免乱码。

    问：我怎么知道假人正在做什么？ 答：看它头顶的悬浮文字即可。悬浮文字会实时显示假人当前的状态，比如空闲、挖掘、战斗、移动等，非常直观。

    问：租赁时钱不够，会怎样？ 答：租赁前会先检查你的余额。余额不足时，指令会被直接拒绝，不会扣费，也不会生成假人，没有任何损失。

    问：可以同时拥有免费假人和租赁假人吗？ 答：可以。免费生成的假人和租赁的假人是分开计算的，互不影响。你可以先免费生成一个，再额外租几个，一起使用。

    问：假人会被别人抢走或者改名吗？ 答：不会。假人有严格的归属机制，只有生成它的玩家和管理员才能操作它。其他玩家既不能指挥它，也不能删除或改名。

    问：假人掉线或者服务器重启后还在吗？ 答：如果服务器开启了假人持久化功能，重启后假人会恢复到原来的位置和状态。如果没有开启，重启后假人就会消失。

    问：我可以同时生成多个假人吗？ 答：这取决于你的个人上限。普通玩家默认只有 1 个免费名额，但可以通过租赁获得额外的假人。如果管理员为你提升了上限，你就能同时拥有更多免费假人。

    问：假人的皮肤和名字是怎么来的？ 答：假人默认使用服务器的皮肤池，部分假人会随机使用稀有皮肤。名字则可以由你在生成时指定，也可以让它自动按顺序命名。

    问：我不小心把假人弄丢了，找不回来怎么办？ 答：先使用 /fpp info 查看假人信息确认它是否还在，再使用 /fpp tph bot 把它传回身边。如果假人真的消失了，通常就是被删除、到期清理或重启未持久化，重新生成一个即可。

    问：怎么让假人跟着我走？ 答：使用 /fpp move bot --to 你的名字，假人会持续跟随你的位置移动。想让它停下来，用 /fpp move bot --stop。

    问：假人挖的东西怎么装进箱子？ 答：先用 /fpp storage bot --enable 给假人登记一个箱子，再让假人干活，最后用 /fpp storage bot --deposit 把假人背包里的物品存进箱子。

    问：怎么查看假人身上带了什么？ 答：使用 /fpp inventory bot 直接打开假人的背包查看，也可以往里面放东西。

    问：怎么让假人蹲下，或者让它站着不动？ 答：用 /fpp sneak bot toggle 切换蹲下状态；用 /fpp freeze bot on 冻结假人让它原地不动，用 /fpp freeze bot off 解除。

    问：假人做了一堆任务，想让它停下来怎么办？ 答：用 /fpp stop bot 停止指定假人的所有任务，或用 /fpp stop all 停止你自己所有假人的任务。

    问：假人的名字能改吗？ 答：可以，使用 /fpp rename bot 新名字 就能修改假人的显示名字。改名同样遵守命名规则，而且头顶的"bot by 你"标识会保留。

    问：假人的移动速度可以调整吗？ 答：假人的移动速度通常由服务器统一设定，玩家可以在设置界面中查看。为了避免异常，玩家一般无法自行把速度调得过快。

    问：假人可以帮我做任务、打副本吗？ 答：假人主要是自动化机械性操作的工具，适合挖掘、点击、挂机等重复性工作。涉及复杂逻辑的任务、需要与 NPC 对话的任务，假人通常无法胜任，请以实际功能为准。

    问：假人在水里或者岩浆里会怎样？ 答：假人会尽量跟随你的指令行动，但在水、岩浆等特殊环境中可能受到影响。请尽量不要让假人走危险的路径，以免造成不必要的损失。

    问：假人能被传送门传送吗？ 答：假人的传送一般依靠指令完成（如 /fpp tph），通过传送门等自然传送机制可能不会生效。需要跨区域移动时，建议直接使用传送指令。

    问：租赁假人和免费假人哪个划算？ 答：如果你只是偶尔用一下，免费假人足够；如果你需要长期挂机、又不想一直占着免费名额，租赁更省心（到期自动清理）。具体可以结合自己的使用频率来选择。

    问：假人会消耗我的游戏货币吗？ 答：普通的生成、操控、传送等操作不会消耗任何货币。只有使用租赁功能（/fpp rent buy）时才会按小时扣费，费用也是事先明确标注的。

    问：假人可以帮我刷资源、刷经验吗？ 答：假人可以帮你自动挖掘、打怪，让挂机更省力。但请注意，任何利用假人绕过服务器限制、影响服务器平衡的刷取行为都是被禁止的，请遵守服务器规则。

    问：我在别人的领地或住宅区能生成假人吗？ 答：这取决于服务器的领地保护设置。如果该区域禁止其他玩家操作，假人也可能无法在那里生成或干活。遇到被拒绝的情况，请尊重领地所有者的安排。

    问：怎么知道服务器上有哪些假人在线？ 答：使用 /fpp list 即可查看当前服务器上所有活跃的假人及其名字。

    十三、实用场景¶

    • 挂机挖矿：生成假人，看着目标矿石，输入 /fpp left-click bot --once，让假人帮你挖掉目标方块。需要连挖时，用 /fpp left-click bot --repeat 持续挖掘。
    • 挂机收经验：生成假人在刷怪塔或怪物农场帮忙打怪，过一段时间回来，输入 /fpp xp bot 收走经验。
    • 长期挂机：使用 /fpp rent buy 24 租一天的假人，到期自动清理，省心省力。
    • 转移阵地：走远之后使用 /fpp tph bot，把假人直接拉回身边，不用跑回去找。
    • 多人协作：和朋友各自生成假人，分工合作，比如一个人负责挖掘，一个人负责收集，效率翻倍。
    • 红石辅助：让假人用右键指令代替你反复触发按钮、拉杆，配合红石机关做自动化测试。
    • 自动收菜：让假人站在农田旁，用右键指令帮你反复催熟和收获作物。
    • 刷怪塔清理：让假人在刷怪塔下帮你清理落下来的怪物，同时用 /fpp xp bot 收走经验。
    • 小跟班模式：用 /fpp move bot --to 你的名字 让假人一直跟着你，去哪都带着它，方便随时指挥。
    • 自动收菜存箱：让假人用右键反复催熟、收获作物，再用 /fpp storage bot --deposit 把产物存进箱子，回家只管取货。
    • 探矿帮手：用 /fpp find bot 钻石矿石 --radius 20 让假人帮你探明附近的矿点，省得自己满山跑。
    • 高处作业：用 /fpp sneak bot on 让假人蹲在建筑边缘干活，防止它不小心滑落摔死。
    • 装备检查：开工前用 /fpp inventory bot 检查假人随身物品和装备，用 /fpp settings bot 调整它的干活方式。
    • 双人分工流水线：一个假人负责挖矿，一个假人负责把矿物存进箱子，你自己负责处理成品，形成一条小流水线。
    • 建筑脚手架：让假人蹲在你建筑的高处帮你搭方块、拆脚手架，省得反复上下跑。
    • 夜间守卫：在家的农田或牧场旁放一个假人，让它在你离开时帮忙清理入侵的怪物。
    • 红石实验助手：需要反复测试红石机关时，让假人定时触发按钮，方便你观察机关运行效果。

    上面的场景都是围绕生成、点击、传送、经验这几条核心指令组合出来的。你可以根据自己正在做的事灵活搭配，比如先租一个假人用于挂机，再用免费假人做另一件事，两个假人分工协作，效率会明显提升。多实践几次，你很快就能找到最适合自己的用法。

    十五、注意事项与服务器规则¶

    使用假人时，请务必遵守以下注意事项：

    1. 不要干扰其他玩家：假人是你的帮手，不是干扰他人的工具。不要在别人家附近乱挖、乱放，不要用假人堵路、挡门。
    2. 不要大量堆放假人：过多的假人会占用服务器资源，造成卡顿。请合理控制假人数量，不用的时候及时删除或停止任务。
    3. 不要利用假人违规：不得利用假人刷取资源、绕过服务器限制、进行任何违反服务器规则的行为。一经发现，将按服务器规则严肃处理。
    4. 注意物品安全：假人挖下的物品会掉在原地，记得及时捡取；贵重物品尽量放在安全的地方。
    5. 及时清理：不需要的假人请及时删除，长期挂机建议使用租赁功能，到期自动清理，避免占用名额和资源。

    十六、结语¶

    希望这份教程能帮助你快速上手假人功能，让你在服务器里的游戏体验更加轻松愉快。假人的每一项功能都不复杂，多用几次很快就能上手。等你熟练之后，就可以根据自己的需要组合使用这些指令，让假人真正成为你在服务器里的好帮手。

    最后再总结几个关键点，帮助你记忆：

    1. 生成：/fpp spawn 生成，--name 可自定义名字。
    2. 干活：对准目标后使用左键或右键指令，--once 干一次，--repeat 反复干。
    3. 找回来：走远了用 /fpp tph 把假人拉回身边。
    4. 收纳：用 /fpp inventory 看背包，用 /fpp storage 存箱子。
    5. 收经验：用 /fpp xp 收走假人攒的经验。
    6. 清理：不用了就 /fpp despawn --own 删除，或者用租赁功能到期自动清理。

    如果使用过程中还有任何疑问，可以随时输入 /fpp help 查看游戏内帮助菜单，或者直接咨询服务器管理员。

    祝你在 ChenRay 服务器玩得开心！
